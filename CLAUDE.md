## Дополнительно для Claude Code

- Скиллы лежат в `.claude/skills/` и подгружаются автоматически — используй их, когда задача совпадает с описанием.
- Встроенный MCP-сервер Studio `Roblox_Studio` объявлен в `.mcp.json` (Windows: `%LOCALAPPDATA%\Roblox\mcp.bat`; macOS — см. `docs/MCP.md`). Если сервер не подключён — так и скажи, не имитируй проверку.
- Разрешения на частые безопасные команды — в `.claude/settings.json`. Личные настройки — в `.claude/settings.local.json` (не коммитится).
- Для крупной задачи сначала составь план (Plan mode) и согласуй его, затем реализуй.
- Для параллельной работы используй отдельные worktree — по одному на задачу.
- Ответы и комментарии — на русском.
