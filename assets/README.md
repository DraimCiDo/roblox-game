# Сцена Roblox Studio

Rojo собирает готовый плейс из трёх моделей. `CorpaLab.rbxm` содержит лабораторию и её игровые точки. `CorpaTerrain.rbxm` содержит воксели из Terrain Editor. `CorpaLighting.rbxm` содержит настройки освещения сцены.

Сектор состоит из спавна, трёх терминалов, пульта добычи, восьми витрин, десяти складских модулей и четырёх створок. Сохраняйте названия игровых объектов при редактировании, чтобы сервер мог привязать к ним действия.

В каждом секторе `Точка входа в трубу` и `Верхняя точка подачи` задают маршрут контейнера до шлюза. `Нижняя точка отвода` задаёт конечную позицию в шахте. `Сигнал подачи` и `Сигнал отвода` задают положение ламп. Точки и лампы должны лежать непосредственно в модели сектора. `Опора над шахтой` постоянно удерживает игроков на уровне площадки.

Секторы расположены в шести внешних крыльях. Зал соединён с каждым сектором крытым переходом. Указатели `Указатель сектора 01` … `Указатель сектора 06` лежат непосредственно в модели лаборатории. Сервер выводит надписи на лицевую сторону указателей и табло секторов.

## Оформление карты кодом (основной способ)

Карта собирается скриптами в `scripts/map/`:

- `hall.luau` — центральный зал: ядро CORPA, разметка пола с дорожками к секторам, колонны с подсветкой, таблички секторов, логотип, свет (Bloom, цветокоррекция).
- `sector.luau` — **сектор игрока целиком**, один шаблон на все шесть: оболочка, бокс открытия над шахтой, стеклянная труба подачи, камера Backrooms с затвором, лаборатория коллекций, автоматизированный склад, галерея витрин, пост заказов и автостенд у входа. Содержимое моделей «Сектор 0N» пересоздаётся полностью (сохраняется только SpawnLocation).
- `corridors.luau` — переходы между залом и секторами.
- `build.luau` — запускает сборщики над `assets/CorpaLab.rbxm` и `assets/CorpaLighting.rbxm` и записывает файлы обратно.
- `check.luau` — проверка контракта секторов (все детали, которые ищет сервер, на месте).

Запуск из корня репозитория: `lune run scripts/map/build.luau`, затем `lune run scripts/map/check.luau`. Сборщики идемпотентны. При запущенном `rojo serve` Studio обновится сам (если декор задвоится — переподключите плагин Rojo).

### Контракт сектора

Сервер (`World.luau`, `Sector.luau`) ищет детали по именам **прямыми потомками** модели сектора; тёзки другого класса недопустимы (`FindFirstChild` может вернуть их). Лицевая сторона (−Z детали) станций, витрин, прилавка коллекций и табличек смотрит в проход; у складского модуля +X — задняя стенка (в стену).

| Деталь | Кол-во | Примечание |
|---|---|---|
| `SpawnLocation` | 1 | вход в сектор |
| `Табло сектора` | 1 | ник владельца (обе стороны) |
| `Заказы`, `Склад`, `Коллекции` | по 1 | станции; в `Заказы` — деталь `Матовый экран заказа`, в `Коллекции` — `Панель каталогизации` |
| `Пульт добычи`, `Индикация шлюза` | по 1 | |
| `Створка шлюза` | 4 | две нижние (y≈−0.35) и две верхние (y≈10.6), 8.8×0.65×17.6 |
| `Опора над шахтой` | 1 | 18.4×1.43×18.4, прозрачная, держит игроков над площадкой |
| `Точка входа в трубу`, `Верхняя точка подачи`, `Нижняя точка отвода` | по 1 | маршрут контейнера (вход — внутри камеры Backrooms, на оси сектора) |
| `Сигнал подачи`, `Сигнал отвода` | по 1 | лампы шлюза |
| `Витрина 1` … `Витрина 8` | по 1 | размеры по `Catalog.DisplaySizes` (6 малых, большая, автостенд) |
| `Складской модуль` | 10 | 1.4×1.4×2.6, 2 колонки × 5 рядов |
| `Затвор Backrooms` | 2 | необязательно: створки затвора камеры, сервер раздвигает их только на время вылета контейнера |
| `Лампа Backrooms` | любое | необязательно: загораются вместе с затвором |
| `Светильник рабочей зоны`, `Рассеиватель витрин`, `Рассеиватель сервисного поста` | любое | сервер добавляет к ним свет |
| `Панель экспозиции`, `Панель заказов`, `Панель склада` | необязательно | подписи зон на лицевой стороне |

Сборщики можно запустить и в Studio (режим Edit) через MCP `execute_luau` — для быстрой визуальной проверки; источником истины остаются скрипты.

## Ручная правка в Studio

Откройте собранный `build/check.rbxl` в Roblox Studio, чтобы редактировать геометрию, которой нет в сборщиках. Чтобы перенести сцену обратно в Git, сохраните плейс в формате **Roblox XML Place Files (.rbxlx)**, затем запустите `python scripts/export-studio-scene.py path/to/scene.rbxlx` (нужен Python) и соберите плейс через `scripts/check`. После ручной правки снова запустите `lune run scripts/map/build.luau`, чтобы оформление легло поверх.

## Правка сцены скриптом

`scripts/patch_scene.py` точечно меняет координаты деталей в `CorpaLab.rbxm` без Studio и Rojo (перенос автомобильных стендов ко входу секторов и терминалов рейтинга к центру зала). Скрипт идемпотентен, проверяет свободное место и сверяет результат с исходником. Запуск: `python3 scripts/patch_scene.py [--check]`.
