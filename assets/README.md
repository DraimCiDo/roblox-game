# Сцена Roblox Studio

Rojo собирает готовый плейс из трёх моделей. `CorpaLab.rbxm` содержит лабораторию и её игровые точки. `CorpaTerrain.rbxm` содержит воксели из Terrain Editor. `CorpaLighting.rbxm` содержит настройки освещения сцены.

Откройте собранный `build/check.rbxl` в Roblox Studio, чтобы редактировать карту. Сектор состоит из спавна, трёх терминалов, пульта добычи, восьми витрин, десяти складских модулей и четырёх створок. Сохраняйте названия игровых объектов при редактировании, чтобы сервер мог привязать к ним действия.

В каждом секторе `Точка входа в трубу` и `Верхняя точка подачи` задают маршрут контейнера до шлюза. `Нижняя точка отвода` задаёт конечную позицию в шахте. `Сигнал подачи` и `Сигнал отвода` задают положение ламп. Точки и лампы должны лежать непосредственно в модели сектора. `Опора над шахтой` постоянно удерживает игроков на уровне площадки.

Секторы расположены в шести внешних крыльях. Зал соединён с каждым сектором крытым переходом. Указатели `Указатель сектора 01` … `Указатель сектора 06` лежат непосредственно в модели лаборатории. Сервер выводит надписи на лицевую сторону указателей и табло секторов.

После изменений экспортируйте модель лаборатории и сохраните обновлённые данные Terrain и Lighting из плейса. Код игры хранится в `src/`.

Чтобы перенести сцену обратно в Git, в Studio выберите **File → Save to File As → Roblox XML Place Files**. Затем запустите `python scripts/export-studio-scene.py path/to/scene.rbxlx` и соберите плейс через `scripts/check`.

## Правка сцены скриптом

`scripts/patch_scene.py` точечно меняет координаты деталей в `CorpaLab.rbxm` без Studio и Rojo (перенос автомобильных стендов ко входу секторов и терминалов рейтинга к центру зала). Скрипт идемпотентен, проверяет свободное место и сверяет результат с исходником. Запуск: `python3 scripts/patch_scene.py [--check]`.
