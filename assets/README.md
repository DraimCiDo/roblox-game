# Сцена Roblox Studio

Rojo собирает готовый плейс из трёх моделей. `CorpaLab.rbxm` содержит лабораторию и её игровые точки. `CorpaTerrain.rbxm` содержит воксели из Terrain Editor. `CorpaLighting.rbxm` содержит настройки освещения сцены.

Сектор состоит из спавна, трёх терминалов, пульта добычи, восьми витрин, десяти складских модулей и четырёх створок. Сохраняйте названия игровых объектов при редактировании, чтобы сервер мог привязать к ним действия.

В каждом секторе `Точка входа в трубу` и `Верхняя точка подачи` задают маршрут контейнера до шлюза. `Нижняя точка отвода` задаёт конечную позицию в шахте. `Сигнал подачи` и `Сигнал отвода` задают положение ламп. Точки и лампы должны лежать непосредственно в модели сектора. `Опора над шахтой` постоянно удерживает игроков на уровне площадки.

Секторы расположены в шести внешних крыльях. Зал соединён с каждым сектором крытым переходом. Указатели `Указатель сектора 01` … `Указатель сектора 06` лежат непосредственно в модели лаборатории. Сервер выводит надписи на лицевую сторону указателей и табло секторов.

## Оформление карты кодом (основной способ)

Внешний вид зала, переходов и секторов собирается скриптами в `scripts/map/`:

- `hall.luau` — центральный зал: ядро CORPA, разметка пола с дорожками к секторам, колонны с подсветкой, таблички секторов, логотип, свет (Bloom, цветокоррекция).
- `sectors.luau` — сектора и переходы: тёмные материалы, неоновые полосы, камера Backrooms в конце трубы подачи (контейнер появляется там и по трубе едет к шлюзу), оформление шахты отвода.
- `build.luau` — запускает оба сборщика над `assets/CorpaLab.rbxm` и `assets/CorpaLighting.rbxm` и записывает файлы обратно.

Запуск из корня репозитория: `lune run scripts/map/build.luau`. Сборщики идемпотентны (повторный запуск даёт тот же результат) и не трогают игровые объекты. При запущенном `rojo serve` Studio обновится сам. Декор сборщики кладут в папки `Оформление зала`, `Оформление переходов` и `Оформление сектора` (в каждом секторе) — их можно пересоздавать свободно.

Сборщики можно запустить и в Studio (режим Edit) через MCP `execute_luau` — для быстрой визуальной проверки; источником истины остаются скрипты.

## Ручная правка в Studio

Откройте собранный `build/check.rbxl` в Roblox Studio, чтобы редактировать геометрию, которой нет в сборщиках. Чтобы перенести сцену обратно в Git, сохраните плейс в формате **Roblox XML Place Files (.rbxlx)**, затем запустите `python scripts/export-studio-scene.py path/to/scene.rbxlx` (нужен Python) и соберите плейс через `scripts/check`. После ручной правки снова запустите `lune run scripts/map/build.luau`, чтобы оформление легло поверх.

## Правка сцены скриптом

`scripts/patch_scene.py` точечно меняет координаты деталей в `CorpaLab.rbxm` без Studio и Rojo (перенос автомобильных стендов ко входу секторов и терминалов рейтинга к центру зала). Скрипт идемпотентен, проверяет свободное место и сверяет результат с исходником. Запуск: `python3 scripts/patch_scene.py [--check]`.
