# Звуки

Все звуки игры описаны в одном месте: `src/shared/Config/Sounds.luau` (имя события → ассет, громкость, высота тона, дальность). Код использует только имя события. Чтобы заменить звук, поменяйте `Id` в этой таблице.

Источники: интерфейс озвучен официальным набором Roblox GUI (клики, уведомления, покупка, выбор), звуки мира — профессиональной библиотекой ProSoundEffects (дерево, металл, воздух, удары). Все ассеты бесплатные (`IsPublicDomain`) из Creator Store.

## Громкость
Кнопка с шестерёнкой слева сверху открывает настройки: два ползунка, «Звуки интерфейса» и «Звуки мира». Они работают мышью и пальцем, действуют сразу, а по отпусканию сохраняются в данных игрока (`VolumeUi`, `VolumeWorld`, по умолчанию 60%). Итоговая громкость звука = `Volume` из таблицы × ползунок. Звуки с полем `Range` считаются звуками мира.

## Как это устроено
- **Клиент** (`client/Audio/Sfx.luau`): `Sfx.play(имя)` — звук интерфейса, `Sfx.playAt(имя, объект)` — звук мира, затухающий с расстоянием. Небольшой случайный разброс высоты тона не даёт повторяющимся звукам звучать одинаково.
- **Сервер** (`server/Network/Audio.luau`): `Audio.at(объект, имя)` — звук в мире для всех, `Audio.to(игрок, имя)` — личный звук игрока. Сервер лишь отправляет событие, воспроизводит его клиент.
- **Запасные звуки.** При старте клиент проверяет доступность каждого ассета (`ContentProvider:PreloadAsync`). Недоступный звук заменяется встроенным звуком движка (`rbxasset://sounds/...`), в Output выводится предупреждение `[Sfx] Звук «…» недоступен`.

## Где какие звуки
| Событие | Звук |
| --- | --- |
| Любая кнопка, слот, узел дерева | `click`, при наведении `hover` |
| Открытие и закрытие меню | `menuOpen`, `menuClose` |
| Уведомления | `notice`; предупреждения и ошибки — `error` |
| Рост баланса, новый уровень | `coin`, `levelup` |
| Заказ, продажа, внесение в коллекцию, витрина, подбор, перк, награда | `order`, `sell`, `deposit`, `place`, `pickup`, `perk`, `claim` |
| Подсказка обучения | `notice` |
| Мини-игра сейфа | `tick` (указатель в зоне), `dialOk` (штифт), `claim` (сейф вскрыт) |
| Шлюзы | `hiss` |
| Доставка контейнера | `whoosh` (в пути), `thud` (приземлился) |
| Коробка | `tape`, `flap`, `confetti` + `thud` |
| Ящик | `snap` (скоба), `woodCrash` (разлёт) |
| Сейф | `clunk` (засовы), `scrape` (дверь) |
| Грузовой контейнер | `latch` (фиксатор), `clunk`, `scrape` (створки) |
| Секретный контейнер | `charge` (с повышением тона на каждой ступени), `boom` (вспышка) |

## Что не проверено
Ассеты взяты из бесплатной библиотеки Creator Store по названию и метаданным, прослушать их без Studio нельзя. Если какой-то звук не подошёл по характеру, замените его `Id` в `Sounds.luau`.
