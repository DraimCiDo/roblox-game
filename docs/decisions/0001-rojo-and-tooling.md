# 0001. Rojo + Git как источник истины для кода

- Статус: принято
- Дата: 2026-11-13

## Контекст
Команда из нескольких людей и ИИ-агентов. Нужны ревью, история изменений, CI и возможность агентам работать с кодом как с обычными файлами.

## Решение
- Код — в `src/` в Git, синхронизация в Studio через Rojo.
- Инструменты закреплены через Rokit: Rojo, StyLua, Selene, Wally.
- Правила для агентов — `AGENTS.md` (общий стандарт), `CLAUDE.md` подключает его.
- Простая архитектура Services/Controllers с собственным Loader без фреймворков (Knit и т.п.).

## Последствия
- Скрипты нельзя править в Studio — изменения потеряются.
- Карта не в Git — хранится в Roblox (Team Create).
- Любой агент с доступом к файлам и терминалу может полноценно работать с кодом.
